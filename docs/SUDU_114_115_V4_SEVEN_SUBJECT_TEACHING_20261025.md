- 從 35 題 Demo 沿用**相同首頁、題目卡、四選項互動、顏色、題號圓球、正解／錯誤選項雙層解說、一眼記住、必要計算式、錯題復習、統測倒數及 RWD**，不另做第二套平台。
- 年度頁 `?year=115`、`?year=114` 的「科目」下拉皆固定顯示七科：**國文、英文、數學 B、商業概論、數位科技、會計學、經濟學**。即使當科尚未核准，也不再從選單消失。
- **三個互斥狀態**：A）正式 `approved/{year}.json` 的已核准題目，支援 A～D、正誤判斷、教師／國小雙層解說與完整計算。B）`approved/preview/{year}.json` 的經影像 QA 原圖，限單題 WebP 唯讀，不輸出題幹文字、選項、答案或教學，也不計分。C）兩者均無，首頁顯示簡潔「尚待驗證」文字，不以 35 題 Demo 偷代題目。
- 首頁仍僅為年度、科目、錯題總復習與倒數；狀態訊息緊貼科目控制項，不新增遮擋題幹的大型 BLOCK。桌面／手機均共用原 V4。
- 已核准數學 B 與尚未核准的其他科目可在同一 V4 透過首頁選單切換，轉到唯讀原圖頁時保留 `year`、`subject`，不改學生歷史紀錄。
- 重要**跨年度教材防錯**：V4 原英文「新聞時事例句」曾只以題號從 Demo config 取例句。現在偵測 `canonicalId` 為正式年度題目時，僅顯示該題正式審核的 `extra['新聞時事例句']` 原文及 `highlights`，絕不套用相同題號的 Demo 假示例或書目。
- 正式年度可作答資料新增 runtime 驗證：非空的題幹、考點、正解、四選項、四份教師＋國小＋理由、教師摘要、國小摘要、一眼記住、來源文字；需要計算者必須具至少兩個完整步驟。違反者**全年度該批載入 fail-closed**，避免不完整教材進入學生作答。
- 未更動官方答案、QA／SQLite、`main`、`approved`、GitHub Pages／學生作答紀錄；新增教材不得因此繞過既有 G0～G10／Reviewer 簽章發布 Gate。

## 3. 任何新題都必須符合 35 Demo 教學體驗

單題入站需完成並驗證：

1. 年度、科目與 canonicalId，嚴格對應官方題號；單題官方原始 WebP 和 SHA，不可混題、整卷或缺圖。
2. 官方原卷核對的完整題幹＋ A～D 選項；有共用材料則分別核對 WebP 與 SHA。
3. 最終官方答案及該年度正確的更正／疑義公告；保留事前解題與答案差異紀錄。
4. `topic`、`concept`、`teacherSummary`、`elementarySummary`、`memory`、`extension` 及可查的 `sourceText`（未知頁碼標「待核對」，不捏造）。
5. `optionExplanations.{A,B,C,D}.{teacher,elementary,reason}` 四選項逐項內容；正解與「解說重點」不可無意義重複。
6. `examCalculation.hasExamCalculation` 真正需要計算才設為 `true`，並逐行提供完整計算步驟；非計算題不產生空的計算框。
7. 英文特化的 IPA／中譯／同反義與難度級別、新聞例句與中譯、來源 URL／日期，**由該題核准資料提供**；不得以 Demo 同題號替換來源。
8. V4 8 種尺寸 × 2 主題，檢查手機觸控、上一／下一題、錯題復習、WebP 對應、解說、highlight、localStorage 隔離與無水平溢出。
9. 真正不同審查者的實質內容複核、受授權的審查簽章、SHA 綁定，以及 publisher stage/check、same-SHA Pages 全量 verify_live 成功，才可稱 LIVE。

**教學草稿存在、資料工程已產出、影像 QA PASS 都不足以直接取得正式可作答權限。** 本 Draft 僅提供各年度各科的正確 UI 接入基礎；尚未補完的題目逐題保持 BLOCKED。
