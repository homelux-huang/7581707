# 各科學習卡片：資料、互動與驗收

更新：2026-10-19（Asia/Taipei）。本文件所屬批次：B1；提交與部署證據見 [SUDU_HANDOFF.md](SUDU_HANDOFF.md)。

## 實作範圍與誠實狀態

`sudu/subject_hover.js`、`subject_hover.css` 與 `data/hover-cards.json` 提供所有科目的卡片互動。互動可用不代表所有詞彙內容齊全。目前只有 **2 筆有查閱來源的詞條**：英文 borrow、國文「畫蛇添足」。其他缺少可靠語境資料的欄位顯示 N/A；沒有新聞資料，不製造新聞引句或日期。

英文和國文的已核對文字／自編練習，題幹及選項均可觸發詞彙卡。官方原題若仍為純影像或文字尚待核實，僅提供題目級卡片，不強行 OCR，也不宣稱圖片具有逐字定位。數學、會計、經濟、商業概論、科技類提供題目級欄位；可靠資料尚缺的欄位保留 N/A。

| 科目 | 欄位 | 已實作內容與限制 |
|---|---|---|
| 英文 | 語境中文、IPA、同義／相關／反義各低中高、新聞、例句 | borrow 的中文、IPA、相關 lend；其他欄位缺漏明示 N/A。裝置發音須點按，並標示合成語音。 |
| 國文 | 讀音、語境義、同義、出處、相關／反義分級、例句 | 畫蛇添足依教育部成語典；例句為自編。其他字詞資料待補。 |
| 數學 | 公式、用法、簡例、日常用法 | 已核實解析或自編練習可用既有原理／步驟；不可靠公式不填。 |
| 會計 | 當年法規、科目、原理、算法、簡例、時事 | 不把現行法規倒套到舊年度，無可靠來源顯示 N/A。 |
| 經濟／商概 | 原理、當年法規、算法、簡例、時事 | 卡片不是逐題教師核實，無法規或新聞資料不補造。 |
| 科技 | 運作、工作原理、算法、簡例、時事 | 按實際年度卷別；未知題目科別不得套用現行考科。 |

「低／中／高」是本站教學分級：日常常用／一般閱讀／抽象或專門。不是 IELTS、TOEFL 或教育部官方級別。同義、相關與反義使用不同欄位。borrow／lend 是同一借貸關係的不同方向，因此列為相關字，不混稱一般反義字。

## 可追溯來源

- [Cambridge Dictionary：borrow](https://dictionary.cambridge.org/dictionary/english/borrow)，查閱日期 2026-10-19。IPA 標明 UK、US；未提供新聞原句。
- [教育部成語典：畫蛇添足](https://dict.idioms.moe.edu.tw/idiomView.jsp?ID=23&la=0&webMd=1)，查閱日期 2026-10-19。例句由本站編寫並明示自編。

詞條新增前須核對所在題目的實際語境，保留來源 URL、查閱日、語音來源／IPA 和分級依據。新聞另須有出版日、原始連結與中文說明；缺一則先保留 N/A。不得把自編例句寫成新聞原句。

## 互動設計

選项內的 A～D 圓形按鈕才提交答案；詞彙按鈕是獨立 DOM 節點，點擊阻止傳遞，因此查字不會答題。桌面 Hover／鍵盤 Focus 可開啟，點按會將焦點移到卡片關閉鈕；Escape 關閉並返回原詞。移入卡片保留開啟狀態，可閱讀、捲動或手動播放語音。離開卡片採 180ms 容許跨隙的時間，與 Header 選單要求的 **0ms 收合**是不同元件。

卡片優先在詞彙側邊，空間不足時選擇上方或下方並限制自身可捲動高度；不會在滑鼠完成點擊時移到觸發詞上方。關閉後不清除作答，重繪題目時會關閉舊卡片。未知或無支援的裝置發音有明確提示，Hover 本身不播放聲音。

## 驗收與待辦

`tests/sudu_browser_smoke.cjs` 使用真正 Chromium，已驗證國文／英文選項點詞不產生 attempt、N/A、Escape、關閉鈕，以及 320、375、390、430、768、1024、1280、1440px × 深淺主題卡片不溢出。該測試亦驗證原卷題只顯示題目級卡片及答題流程。

仍待逐題語境詞庫、可授權的可靠發音來源、大量同／反義詞審核與有日期的新聞補充。這些內容工作不可用卡片元件存在或 2 筆示例宣稱完成。
