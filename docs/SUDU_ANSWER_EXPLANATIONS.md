## 四項核實與答案配對分離

| 欄位 | 證明範圍 |
|---|---|
| `questionVerified` | 原題題意、選項、公式、圖表、共享題組與跨頁已完整核對 |
| `answerMatched` | 程式將本題號對到官方答案候選，可能仍有分卷、錯位或更正問題 |
| `answerVerified` | 正確卷別、題號、所有可接受答案與更正公告已獨立覆核 |
| `teachingVerified` | 這一題教師詳解、逐選項理由與延伸題已實質覆核 |
| `textbookVerified` | 教材出版社、書名、冊次／章節及可確認頁碼已查證 |
| `scoringNeedsReview` | 原題或答案來源改變後，禁止沿用過期配分結果 |

`answerReviewedBy`／`answerReviewedAt` 或 `verification.answer` 保存覆核人與時間。AI 產生內容只算草稿；程序不能因成功呼叫模型、欄位齊全或有通用觀念卡就把四項旗標全改為 true。

### 舊答案旗標遷移

接手資料有 4,304 筆 `answerVerified: true` 只是程式配對，沒有逐題覆核人／時間。本批執行 `scripts/tcte_verification_migrate.py`，將這些改為 `answerMatched: true`、`answerVerified: false`；`answerVerificationLegacy` 保存原 true、原因、migration ID、時間與原 commit，年度 `verificationMigrations` 保存遷移前 JSON SHA256。`sourceVersion` 保存已知 PDF hashes 與內容版本；尚未知的來源 hash 保持空值，不捏造。

遷移 ID 是 `separate-answer-match-v1`。首次更正 26 年、4,304 旗標；第二次執行更正 0，確認可重複執行。另逐欄比對原始 5,323 筆的 ID、year、paper、number、question、options、answer、acceptedAnswers，**變更為 0**。新增的 100 筆僅為 93 年已核對封面題數的原圖導覽紀錄；原學生 localStorage、IndexedDB、首次錯答、已送出快照及備份格式都不由這支 migration 讀寫。

48 筆封面說明疑似偽題不刪除 ID，以 `original_image_required` 及 issue 標記，原文字保留作稽核。480 筆舊擷取占位、92 筆未覆核 OCR 亦如實待核實，不能當正式題幹生成詳解。新的 importer 會先排除明確封面指令，避免封面第 1、2、3 點搶走真正題目 ID。

## 每題完整教師詳解標準

1. 先確認官方原卷題意、四個選項、必要圖表與所有共享題組；看不清的題目先查 [平台原始 WebP](SUDU_ORIGINAL_IMAGES.md)，不靠猜測。
2. 保存官方正解與答案來源。多個官方接受答案、送分或更正需同時記錄，另一個合法選項不可被教成錯誤。
3. 提供高職該科核心原理、白話解說與必要步驟。計算題列公式、數值、單位及推算；會計可列分錄；語文解釋語境。不同科目不可套同一組不適用欄位。
4. `wrongOptions` 保持四個位置，對應原 A–D：正確選項說明正確條件，其他選項指出具體錯誤觀念或條件。只有「不符合題意」不算完整理由。
5. `practice` 至少一個完整四選項自編延伸／反向題，保存題目、選項、answerIndex、步驟與白話解析，明示自編，不能冒充官方試題。
6. 記錄教材、課綱、官方卷與可核對延伸閱讀。優先查彰化高商當年採用版本；找不到確定章節就顯示「精確章節待核實」，不編書名、章節或頁碼。
7. 歷史法規按該年適用規則解題；現行法規、新聞案例另記日期，不反過來覆寫歷年官方答案。
8. 核心術語可 Highlight；會計術語依前端指定黑底白字。Hover 卡片的通用資料只是補充，不算完成該題解析。

目前 `tcte_teaching.py` 只允許 `questionVerified`、`answerVerified` 皆 true、四個可靠選項齊全且沒有缺圖／OCR／封面疑義者進入 AI 草稿流程。草稿強制保留 `teachingVerified: false`，記錄來源版本與模型生成記錄；教材核實獨立。現在符合的題目數為 0，不能為了大量產生解析而降低條件。

## 來源變動與既有教學保留

`tcte_preserve_teaching.py` 的穩定指紋包含年度、卷別、原題號、科目、題幹、選項、官方答案／全部接受答案、來源 URL、問題 PDF 與答案 PDF hash。英文只正規化多餘空白，不移除詞與詞邊界，以免 `now here` 被誤視為 `nowhere`。

同內容再次匯入會保留已覆核解說與四項旗標，教材旗標不依賴教學旗標。任一來源或接受答案改變時先存 `verificationHistory` 的完整舊 snapshot、version ID 和原因，再使受影響分項待覆核；不可只因數字答案相同就略過 PDF 更換。新匯入缺少的舊題保存在年度 `retiredQuestionVersions`，不默默刪除其 ID 與證據。重複匯入不重複增加相同 history。

原圖重新壓縮只改圖片呈現版本；來源 PDF bytes 不變時不清空學生作答，也不使已覆核文字無故失效。來源 PDF bytes 真正改變，原圖 renderer 同時保存舊索引和題目歷史並阻擋過期答案／教學／計分。

## 答後閱讀與排序相容

答題保存、白話解說優先捲動、回題目、prefers-reduced-motion、自訂區塊排序與浮動題號列的介面規則由 [導覽位置文件](SUDU_UI_NAVIGATION_POSITION.md) 和 [RWD／可及性驗收](SUDU_UI_RWD_AND_ACCESSIBILITY.md) 記錄。資料缺乏可靠官方正解或解說時，顯示待核對／N/A，不能讓一個通用 placeholder 看起來像完整教師講解。原卷與官方來源仍保留在每題及錯題頁，不因移除選單入口而刪除。
