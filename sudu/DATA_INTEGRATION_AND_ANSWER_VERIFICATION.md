# 115 題庫跨 Session 接入與答案一致性規格

更新：2026-10-22（Asia/Taipei）

## 分工與開放範圍
資料 Session 已獲授權處理 115 年七科完整原題、單題 WebP、OCR 與資料庫；本主開發 Session 負責讀取同一倉庫的交付成果、驗證接入、獨立解題、教學解說、平台程式、UI、測試與部署。本 Session 不重做裁圖或 OCR。
資料準備完成不代表全年題目已獲准上線。學生 LIVE 仍限已約定的七科各五題，擴大教學與開放全年需使用者明確確認。

## 接入順序
1. 讀取交付 PR／commit、DATA_HANDOFF.md、schema、manifest 與核對報告，固定來源版本。
2. 以年度＋試卷代碼＋官方題號建立穩定 ID；保留科目映射。不得更動既有學習紀錄鍵或覆寫作答歷史。
3. 驗證圖片引用、資料完整性、公式／表格／共用材料與資料庫讀回。問題回報資料 Session，不自行猜補題目。
4. 建立不含題庫答案的解題輸入，僅提供完整題幹、選項、必要圖片與材料。先保存 AI 解題結論、推導、模型／方法、時間與輸入版本，再開啟題庫答案比較。
5. 比較通過後完成逐選項解說、計算過程與 UI 驗收，才列入可供學生正式作答的題目。
6. 透過 GitHub Actions release gate 部署，核對實際 LIVE release SHA；未成功不得稱已部署。

## 答案核對資料
逐題保存 questionId、questionRevision／contentHash、assetHashes、answerSourceRevision、answerSourceHash、acceptedAnswers、aiAnswers、aiReasoning、aiSolvedAt、comparisonStatus、reviewNotes、teachingStatus。
AI 結論必須來自獨立解題，不得從 q.answer 複製或用官方答案倒推理由。
目前既有教學草稿是在已見答案的情況下編寫，不可因此標成已完成獨立核對；接入後仍須另行驗證。

## 狀態與學生使用條件
- pending：尚無完整獨立解題或來源未核對；顯示「答案尚待核對」，不列為完成，不進正式判分。
- insufficient_source：題幹、選項、圖表或公式缺漏；顯示「題目資料不完整，暫停作答」。
- mismatch：AI 解答與題庫解答不一致；題目卡最上方、題幹與圖片之前，顯示大字警示：
  **AI 解答與題庫解答不一致**
  下一行顯示 AI 答案、題庫答案與待核對原因。禁止標示完成，暫停判分與正式作答。
- matched：獨立答案與已核對的題庫答案相符，且輸入版本一致；仍需教學完整、圖片資料與 UI 驗收通過，才可發布。
- source_dispute：雖有答案配對，但推導與題目條件存在疑義；仍不通過發布，不可為配答案硬編解說。

單選題正規化字母後比較；官方接受多種單選答案時，AI 的單一確定答案須屬官方接受集合。複選題比較完整集合，不能僅有交集就通過。取消、送分或特殊評分題按官方規則另行處理，不能冒稱普通一致通過。
題目、選項順序、必要圖片或答案來源變動，舊核對結果立即失效，重新驗證。

## 警示與作答保護
警示使用醒目高對比底色、大字標題與文字說明，不只靠顏色；適用深淺主題、手機與桌機，必要時使用 role="alert"。
待核對題目不可有綠色通過標示。停用答案按鈕之外，判分函式也須檢查核對狀態，不能靠程式呼叫繞過。
保留歷史作答紀錄，不追溯清除。開發預覽可以顯示未通過題目，但不能包裝成正式可用題目。

## 教學完成條件
正確與錯誤選項各有「高職老師：白話文解說」與「國小生也懂」一段說明。
計算題列公式意義、適用條件、數值代入、逐步算式、單位與檢查，不能只給公式。
另設範例需標示為教學假設，不能混入原題條件。
一眼記住、重點解說、關鍵字詞與重要算式使用 highlight 與粗體。
資料疑義不得以教學內容掩蓋；保留待核對頁碼與來源。

## 驗收
至少驗證一致、不一致、未核對、缺資料、多答案、資料版本變動失效、停用判分與歷史紀錄保留。
確認不一致警示位於題目最上方，八組 RWD 與兩種主題可讀。
本文件為接入與發布規則；文件提交不代表上述執行閘門已接入 LIVE，也不代表新資料 Session 已完成交付。
