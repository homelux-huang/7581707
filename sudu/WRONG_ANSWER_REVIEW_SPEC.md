# 7581707｜答錯題重點復習與 115 全科 5 題 LIVE DEMO 規格

更新日期：2026-10-21

## 目標

在 V4 最終版面上方選題 Block 加入「答錯題重點復習」入口。此功能不是另一套 UI，而是現有作答流程的錯題加強模式。

目前 DEMO 範圍只從 115 年已存在的題庫選題，每個學習科目 5 題：

- 國文 5 題
- 英文 5 題
- 數學 B 5 題
- 商業概論 5 題
- 數位科技 5 題
- 會計學 5 題（沿用已校正第 2～6 題）
- 經濟學 5 題

合計 35 題。這不是完成 115 全題庫，只是跨科 LIVE DEMO。

## 答錯題重點復習

入口位置：上方題號／進度 Block，和「重新作答」「續答」同一功能列。

可依下列條件篩選與排序：

1. 科目：全部或指定科目。
2. 答錯次數：錯最多次排最前面。
3. 答錯耗時：只統計答錯作答的時間，花費最多時間者排最前面。
4. 最近答錯：可供學生快速回到最近失誤。

每一張復習卡必須把「題目＋正確答案」放在一起，並顯示：

- 一眼記住
- 觀念
- 延伸閱讀
- 公式／分錄

錯題歷史不能因「重新作答」而刪除；重新作答只清空目前科目的本輪畫面狀態。

## 各科目加強欄位

### 英文

除共同欄位外，加上：

- 中文翻譯
- 發音
- 同義相關單字：低／中／高難度
- 反義相關單字：低／中／高難度
- 新聞時事例句

IELTS、TOEFL 或近 3 年時事只作為學習語境來源；DEMO 的時事例句若由 AI 改寫，須標示為學習示例，不冒充原新聞逐字內容。沒有相關內容時自動隱藏。

### 數學

除共同欄位外，加上：

- 公式
- 用法
- 簡易範例
- 日常用法

無相關內容時自動隱藏。

### 會計

除共同欄位外，加上：

- 法規
- 會計科目
- 會計原理
- 算法
- 簡易範例
- 日常時事用法

無相關內容時自動隱藏。

### 國文

除共同欄位外，加上：

- 讀音
- 同義字
- 出處
- 相關字詞：低／中／高難度
- 反義字詞：低／中／高難度
- 例句

近 3 年時事內容可以由 AI 產生學習語境例句，但不可偽稱新聞原文。無相關內容時自動隱藏。

### 經濟學

除共同欄位外，加上：

- 經濟原理
- 法規
- 計算邏輯
- 日常範例
- 近 3 年新聞時事案例解說

無相關內容時自動隱藏。

### 商業概論

除共同欄位外，加上：

- 法規
- 原理
- 邏輯
- 日常範例
- 近 3 年新聞時事案例解說

此科若某欄位沒有相關內容，不隱藏，顯示 `N/A`。

### 數位科技

目前需求沒有指定額外專屬欄位，因此 LIVE DEMO 先保留共同欄位；後續可再補資訊安全、編碼、通訊、雲端、AI／資料等專屬學習卡。

## 排序資料模型

每題至少保存：

- attempts
- wrongCount
- totalWrongSeconds
- lastWrongAt
- lastElapsed
- selected
- latest status

GitHub Pages DEMO 使用 localStorage。正式雲端版才接後端帳號、round 與 attempts 資料表。

## UI 原則

- 延用 V4 大字、大卡片、大觸控區。
- 不回到舊 GitHub 平台 UI。
- 深色模式背景純黑。
- 上方功能列維持兩列式：第一列功能，第二列五顆題號球。
- 「答錯題重點復習」入口需在上方選題 Block 可直接看到。
- 手機單手操作，按鈕至少約 44～48px。
- 復習卡不可水平捲動。
- 共同欄位與科目專屬欄位使用相同卡片視覺，但內容依科目切換。

## 資料完整性

- 不重新 OCR。
- 不重做既有會計第 2～6 題與其單題 WebP。
- 115 原始題庫目前的自動配對答案不是全面人工複核答案；LIVE DEMO 只用於 UI／學習流程驗證。
- 原始題幹若含圖表而 DEMO 沒有對應單題 WebP，不用整張試卷代替，也不偽造圖片。
