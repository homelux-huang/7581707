# 7581707｜答錯題重點復習與 115 全科 5 題 LIVE DEMO 規格

更新日期：2026-10-21

## 目標

在 V4 最終版面 Head 保留「答錯題重點復習」入口。此功能不是另一套 UI，而是現有作答流程的錯題加強模式。

目前 DEMO 範圍只從 115 年已存在的題庫選題，每個學習科目 5 題：

- 國文 5 題
- 英文 5 題
- 數學 B 5 題
- 商業概論 5 題
- 數位科技 5 題
- 會計學 5 題（沿用已校正第 2～6 題）
- 經濟學 5 題

合計 35 題。這不是完成 115 全題庫，只是跨科 LIVE DEMO。

## 答錯題重點復習

入口位置：Head；不放在可自動隱藏的選題 Block。

可依下列條件篩選與排序：

1. 科目：全部或指定科目。
2. 答錯次數：錯最多次排最前面。
3. 答錯耗時：只統計答錯作答的時間，花費最多時間者排最前面。
4. 最近答錯：可供學生快速回到最近失誤。

每一張復習卡必須把「題目＋正確答案」放在一起，並顯示：

- 一眼記住
- 觀念
- 延伸閱讀
- 公式／分錄
- 出處（優先彰化高商教材：學校／版本／章節／章節名稱／頁數；無法核實頁碼時顯示「待核對」，不得臆測）


錯題歷史不能因「重新作答」而刪除；重新作答只清空目前科目的本輪畫面狀態。

## 教材出處規則

共同欄位新增「出處」，顯示格式：

`國立彰化高商｜教材版本｜章節｜章節名稱｜頁數`

優先順序：

1. 國立彰化高商公開教科書書單確認之版本。
2. 彰化高商統測模擬考範圍表確認之章節名稱。
3. 若彰化高商版本／內頁無法取得，再改用教育部審定、台灣技高常用教材，並明確標示出版社與版本。
4. 未取得可核驗的內頁時，頁數顯示「待核對」，不得自行推測或填假頁碼。

目前可確認的彰化高商教材家族：

- 國文：依冊次使用東大／龍騰／翰林技高國文。
- 英文：龍騰《英文(B版)》。
- 數學 B：東大《技高數學B》。
- 商業概論：啟芳《商業概論（上／下）》。
- 數位科技：旗立《數位科技概論（上／下）》。
- 會計學：啟芳《會計學（一～四）》。
- 經濟學：旗立《經濟學（上／下）》。

公開依據：

- 彰化高商 113 學年度第 2 學期各班教科書書單。
- 彰化高商 111 學年度四技二專模擬考專業科目範圍表（108 課綱章節名稱）。

- 英文每一個選項至少顯示該字的中文翻譯與發音；正確選項再顯示同義、反義與時事語境。

- 商業概論缺少內容的欄位維持 `N/A`；其他指定科目無內容則自動隱藏。

## 答題後「一眼記住 → 正確解答」流程

- 學生送出答案後，「一眼記住」必須立即顯示，不需再點任何按鈕。
- 視覺順序固定為：一眼記住 → 正確解答 → 四選項詳解。
- 系統自動捲動到正確解答框；定位依實際 DOM 高度計算，不寫死。
- 「一眼記住」下緣使用綠色重點線，正確解答框上緣使用相同綠色重點線；左右邊界與寬度需對齊。
- 兩框之間保留約 8～12px 安全距離，目標約 10px，避免互相遮蓋。
- 一眼記住內四個大型功能改為「觀念／延伸觀念／公式・分錄／出處」，各自使用不同高對比色簡圖 icon。
- icon 色彩：觀念藍、延伸觀念紫、公式／分錄橘棕、出處青綠；淺色與深色模式皆需維持可讀性。

## 題目卡／答案卡 UI 與單題 WebP 規則

- 題目與原圖使用獨立的淡藍題目卡；四選項使用另一張淡暖色答案卡，兩卡間保留空間。深色模式採深藍題目卡與深棕答案卡。DOM 分開為 `questionCard`／`answerCard`，不得只在同一張白卡內改小區塊底色。
- 未判分的答案選項在滑鼠 hover 時要有平滑的背景色、邊框、陰影與位移動態；判分後的紅／綠狀態優先，不可被 hover 覆蓋。
- 所有科目、所有正式題目都必須在題目文字下方顯示「該題自己的單題 WebP」。
- 單題 WebP 僅可包含：該題題號、完整題幹、該題必要圖表／共用閱讀材料、A～D 答案選項。
- 嚴禁使用整張試卷頁面直接代替單題 WebP；也不得包含上一題或下一題的題幹／選項。
- 單題圖由既有官方頁面 WebP 做純座標裁切；不可重新 OCR、不可重畫文字、不可用 AI 生成或改寫考題影像。
- 目前 115 LIVE DEMO 的會計第 2～6 題沿用既有單題 WebP；其餘 30 題依 `sudu/demo-question-crops.json` 由 GitHub Pages build 產生單題 WebP。
- GitHub Pages build 會輸出 `sudu/questions/115/crop-manifest.json`，記錄來源頁面、裁切座標、輸出尺寸與 SHA-256，以利回溯。
- 目前只完成／驗證 7 科 × 5 題 LIVE DEMO；以上規則同時列為未來 115 全題庫的強制匯入驗收條件，在使用者確認 Demo 前不得開始全面製作。

- 進入「答錯題重點復習」時，完整隱藏選題 Block 與手機「題號」開關；滑鼠靠頂端也不得滑出。返回作答或回到原題才恢復作答頁規則。
- 三個控制項：「復習科目」淺藍＋書本 icon、「錯題排序」淺紫＋排序 icon、「返回作答」淺綠＋返回箭頭 icon。

## 2026-10-22 手機單手操作修訂（取代舊版一眼記住置頂規則）
- 正確解答下方才是一眼記住，採正常文件排版，不 sticky、不覆蓋題目。

- 底部保留題目／解說／錯題三個大型按鈕；題目綠底白字，錯題紅底白字。

## 一眼記住與解說重點連接
- 正確解答後為同一組閱讀區：一眼記住 → 解說重點；兩者直接相接，間距 0、左右同寬，接縫無圓角。
- 其他答案選項及判分結果不得插入這兩區之間。
- 解說重點置於 memoryWrap 中，關閉、回題目與再次開啟解說時，整組同步隱藏／顯示。
- 8 組 RWD 與雙主題逐題檢查相鄰 DOM、零間距及寬度對齊。

## 國文級別與三科考題計算式
- 國文低／中／高顯示為初級／中級／高級，所有選項、解說、一眼記住延伸及錯題卡共用格式化。
